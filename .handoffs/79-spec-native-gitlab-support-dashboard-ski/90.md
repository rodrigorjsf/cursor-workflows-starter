## Decisions & deviations
- **0.4.0, not 0.3.1.** `v0.3.0` is already tagged and released (de379b5). The `gh` to `forge` id change is breaking for `wf doctor --json` consumers; the repo is pre-1.0, so the minor moves.
- **The git tag `v0.4.0` is not created here** (release step of the maintainer, as for 0.3.0 and `#21`). The pins point at a tag that will exist once the run-spec PR is merged and tagged.
- **One new test** (`test/repo-layout.test.ts`): the changelog has `## <package version> (pré-release, YYYY-MM-DD)`. The Spec reviewer called it low-risk scope creep; kept, because it is the first acceptance criterion in test form ("version bumped, with a changelog entry"). This changes the maintainers' order of work slightly: a version bump now needs its changelog heading in the same change (written in `CODING_STANDARDS.md:19`).
- `CODING_STANDARDS.md:19` gained one sentence on the release step (rename the section, the next entry opens a new `## Não lançado`). Not a `CLAUDE.md`/`AGENTS.md` edit.
- The kit-range examples (`>=0.3.0 <0.4.0` in the schema's `kit` example and description, and in the invocation chapter) moved to `>=0.4.0 <0.5.0` / `^0.4.0`, as the previous bump did (84c59b7): they describe what `wf init` writes for the current kit.
- Untouched on purpose: `packages/runtime/test/install.process.test.ts` (its stand-in origin releases 0.3.0 and builds its own newer ones), the older CHANGELOG sections, `.handoffs`.
- Not done: the date is the day the work was done (2026-11-13, same as the 0.3.0 heading); the maintainer may adjust it when tagging.

## Learnings
- `MISE_TRUSTED_CONFIG_PATHS=<worktree>` does not persist across Bash calls: prefix every `mise exec` with it.
- `npm run test -w @cursor-workflows/runtime -- <file>` still runs the whole glob (the script already ends in `test/*.test.ts`): run `tsx --tsconfig tsconfig.test.json --test <file>` from inside the package, with mise trusted, to run one file.
- A timing-bound runtime test (`exec.process`, `cancel`) can fail when the machine is at load average 10+: rerun `npm run check` before suspecting the change.
- A changelog bullet that shifts `CHANGELOG.md:7` breaks `coding-standards.test.ts` (the `_See:_` cite must stay on a non-blank line): keep a bullet on line 7 or repoint the cite.
