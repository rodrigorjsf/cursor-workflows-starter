## Learnings
- `git add <paths>` aborts entirely when one pathspec does not exist: the first commit then held only the staged renames. Check `git show --stat HEAD` after committing (caught and amended).
- A hoisted `tsx` is not under `packages/runtime/node_modules`: load it with `node --import "$(import.meta.resolve('tsx'))"` or `node_modules/.bin/tsx` from the root.
- To run a spawned runtime offline use `TSX_TSCONFIG_PATH=<package>/tsconfig.test.json` (swaps `@cursor/sdk` for the fake); MCP `StdioClientTransport` needs `getDefaultEnvironment()` merged into `env` or the child loses `PATH`.
- Two processes running the suite in one worktree can collide on `test/.tmp`; reviewers running `npm test` while another does is enough.
- Use `mise exec node@22.23.4 --` for every npm/node command here.
