## Learnings
- A fresh worktree has no `node_modules`: `npx tsx` still works (it walks up to the main checkout), but root tests spawn `<worktree>/node_modules/.bin/tsx` and fail with ENOENT until `npm ci` runs there.
- `git add <paths>` aborts entirely when one path no longer exists, such as a file already staged with `git rm`: drop it from the list and check `git log -1 --stat` (the first commit attempt committed nothing).
- Distributed skill text is checked for Portuguese outside code spans: put a pt-BR chapter or section name in backticks.
- `gh issue view N` prints nothing through the Bash tool here; use `--json title,body` (or `--jq`).
- `git commit --trailer` several times keeps all trailers in the last paragraph, including an attribution trailer.
