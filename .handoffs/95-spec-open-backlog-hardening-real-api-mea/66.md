## Decisions & deviations
- **Reminder on its own line.** The passing message is `key "<name>"` + `\n` + the reminder, not one long line: the text report indents continuation lines, like other multi-line messages. A pass carries no `hint` (the healthy-setup test asserts none), so the reminder lives in `message`.
- **Step 4 when the user says "off".** The ticket only says not to continue until the user answers. I wrote: a user who says it is off or does not know finds the setting (or asks the admin) and reports back; going on with it off is the user's call, not the agent's. The agent never reads, guesses or changes the setting.
- **The guide's doctor step** says the passing `login` message ends with the reminder and that step 4 already asked, so nothing more is due. Without it an agent could read the reminder as an unanswered warning.
- **Facts about Cursor beyond the ticket's text** (mode off: "may use and store codebase data, prompts, editor actions, code snippets", providers "may temporarily access and store model inputs and outputs"; mode on: no training by Cursor, but a prompt that trips an abuse detector may be stored; "Cursor maintains zero data retention (ZDR) agreements with all providers"; "Non-ZDR models will be designated as such or require an admin to opt-in"; "Even if you use your API key, your requests will still go through our backend!") come from `https://cursor.com/data-use`, read twice on 2026-11-14 through a summariser that returned the same sentences. The chapter cites the page with that date. "Own API key falls outside the ZDR guarantee" is the ticket's decision; the chapter says what the page states and tells the reader to treat the own key as outside, because the ZDR agreements are Cursor's with the providers.
- `INSTALL-AGENT.md` is pinned to `v0.4.0` and now describes a step the `v0.4.0` copy of the guide lacks: like the rest of the unreleased docs on main, it becomes true with the next release.
- `templates/global-config.json` keeps `allowedModels: null` (the ticket changes advice, not the default).
- New shared helper `sectionOf` in `scripts/lib/markdown.ts`, used by `test/security-md.test.ts` and `test/privacy-mode-docs.test.ts` (it was a byte-for-byte copy in both).
- No `CLAUDE.md` or `AGENTS.md` edited.

## Learnings
- `WebFetch` on a vendor page returns a summariser's text: ask twice for verbatim sentences, cite the date read, and put "or"/"and" back as the page has them.
- `packages/runtime/test/doctor.process.test.ts` takes about 3 minutes alone: run it with `run_in_background`, and do not edit `src` while it runs (spawned `wf` processes load the files fresh).
- The harness changed the session's primary working directory to another ticket's worktree mid-run; keep `git -C <WORKTREE>` and absolute paths, never `cd` to it.
