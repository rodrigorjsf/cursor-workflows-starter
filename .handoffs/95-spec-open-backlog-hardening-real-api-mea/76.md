## Learnings
- `parseArgs` at the top of a script runs when a test imports it, and strict mode throws on the importer's flags: read `argv` inside `main(argv)`.
- An interface is not assignable to `Record<string, unknown>` (no implicit index signature); a type literal alias is. A conversion to `interface` can fail at the call that hands the value to a `Record`.
- A CSS check that needs to see declarations must split at `;`, `{` and `}` only outside strings and parentheses (`calc()`, `url()`, `content: ";"`), and keep comment newlines so line numbers hold.
- The chrome-devtools MCP did not connect in this run: a CSS change cannot be looked at, so keep such changes within the scale step (at most 2px here) and say so.
- A `.mts` helper that imports `typescript` must live inside the worktree to resolve it; delete it before committing.
