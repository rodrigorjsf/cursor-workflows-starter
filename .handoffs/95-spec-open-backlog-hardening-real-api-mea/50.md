## What was built
ADR-0010 ("Detached jobs, and how each one is cancelled", `docs/adr/0010-detached-jobs-and-how-each-is-cancelled.md`, book chapter 7.10) supersedes ADR-0003.
- It restates what ADR-0003 decided and still holds (detached child owns the run, heartbeat, one process per run, SIGINT/SIGTERM, chat agent cancels only on request, Linux/WSL2).
- It defines the three job states (running, frozen, dead) and records every cancel path: running = SIGTERM, revert, `cancelled`; frozen = SIGSTOP, kill of the recorded `ctx.exec` groups and the detached children, SIGKILL of the job and its own group, no revert, job stays `failed` and resumable, `killedByCancel`, then the cloud agents are cancelled; dead = no signal, only the left cloud agents are cancelled.
- ADR-0003's status is now `superseded by ADR-0010` (text untouched). Index (7.3 note, new 7.10 line), neighbour footers (ADR-0009, 8.1 chapter), CHANGELOG, and the four chapters that cited ADR-0003 as the decision in force now point at ADR-0010.

## Learnings
- A new ADR in the book needs four edits besides the file: the index line (and the "(substituído pelo ADR-NNNN)" note on the old one), the previous ADR's footer, the footer of the chapter that followed it (`npm run docs:check` prints the expected text), and the ADRS list of `test/vision-and-adrs.test.ts`.
- A regex with the `m` flag treats `$` as end of line: for "to the end of the text" use `(?![\s\S])`.
