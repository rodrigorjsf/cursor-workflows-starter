## Decisions & deviations
- **Env var `WF_DOCTOR_WSL_INTEROP_FILES`** (a PATH-style list) is the injection: the ticket says "the path is injectable for tests" and the tests spawn `wf`. Read in one accessor (`interopFiles()` in `doctor.ts`, per CODING_STANDARDS Configuration). Documented in the book's `host` row as tests only.
- **`host` is the 11th and last check**, so scripts that read `--json` by index keep working. Every text and test that listed ten checks says eleven.
- **Statuses:** a missing file passes; a file whose first line is not `enabled` passes; a file that exists and cannot be read **warns** (the doctor cannot tell). Beyond the ticket, which names only enabled and absent.
- **`WSLInterop-late` is read too** (beyond the ticket's single path): microsoft/WSL#8843 shows a systemd distribution registering interop under that name, so a host with interop on would pass if only `WSLInterop` were read. `enabled` in either file wins. See Absorbed.
- **The doctor's hint says "the paragraph on WSL" in SECURITY.md**, not the pt-BR heading: `packages/runtime/test/messages-english.test.ts` forbids Portuguese strings in runtime source.
- **Spend limit wording:** the dashboard limit is named as the cap that also binds a leaked key (ticket), plus the honest caveat from 5.1 that Cursor's docs do not say whether the per-member limit counts SDK usage.
- **SDK telemetry row** written from the bundled `@cursor/sdk@1.3.1` (`dist/esm/index.js`): events `sdk.run.created`, `sdk.run.completed`, `sdk.run.send_latency`, `sdk.operation.failed`, `sdk.executor.startup`, `sdk.request.pr_opened`, sent with the user's key to `CURSOR_BACKEND_URL` or `https://api2.cursor.sh`, each with SDK version, platform and arch. No switch to turn it off found (read 2026-11-15); the row says the kit did not measure the payload or whether Privacy Mode changes it. The Spec reviewer re-verified this against the package.
- **Cloud VM row facts** (retention: conversation history indefinite by default, Enterprise cap of 90 days, environment snapshot deleted after 30 days idle, Delete Agent API leaves snapshots; legacy Privacy Mode unsupported) are from https://cursor.com/docs/cloud-agent/security-network, fetched 2026-11-15. WSL facts from the Microsoft pages on file permissions and `wsl.conf`; GitHub facts (security log 90 days, export, vigilant mode) from GitHub docs, fetched the same day.

## Learnings
- `packages/runtime/test/messages-english.test.ts` rejects a Portuguese string literal in runtime source (accented letters and a word list): point at a pt-BR doc heading in English prose, never with a constant.
- This machine is WSL with interop on: any test that runs `wf doctor` needs `WF_DOCTOR_WSL_INTEROP_FILES` pointed at its own file, or the `host` check warns.
- `\\wsl$` outside a Markdown code span renders as `\wsl$`: put it in backticks.
- Docs tests that look for a phrase in hard-wrapped Markdown must collapse whitespace first; a checklist item spans several lines, so split on the `- [ ]` marker, not per line.
- A single `doctor.process.test.ts` run can pass the 180s foreground limit when many tests fail; redirect it to a file in the scratchpad.
- Fresh worktree: `mise exec -- npm ci --prefer-offline` takes about 3 seconds.
