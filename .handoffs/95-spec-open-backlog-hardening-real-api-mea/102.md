## Learnings
- A single package test file: run it from `packages/runtime` with `--tsconfig tsconfig.test.json`; without it the run took minutes.
- `parseRemote` reads `host:3000/g/p` as an scp-like remote (host `host`, path `3000/g/p`), so a port in a scheme-less repo never reaches the segment rule.
- `cmd > log &` in a Bash call detaches the suite (repeat of the #71 learning): use `run_in_background` on the bare command.
