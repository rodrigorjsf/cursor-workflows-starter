# Contribuindo

O guia de contribuição é o capítulo [9.1 · Contribuindo](docs/contributing/01-contribuindo.md) do livro, na parte
[9 · Contribuindo](docs/README.md#parte-9--contribuindo).

Antes de abrir um PR, rode `npm ci` e `npm run check` (typecheck e todos os testes). A política de custo dos testes contra a API real
está em [9.1 §Testes contra a API real: política de custo](docs/contributing/01-contribuindo.md#testes-contra-a-api-real-política-de-custo).
